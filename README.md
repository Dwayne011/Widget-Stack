# Widget Stack

An Android app that lets you stack several home-screen widgets in one slot and
swipe between them, the way Samsung One UI (and iOS) do, on any launcher.

Status: **spike**. The code in `app/` exists to answer one question: can a
normal app relay other apps' widgets, live and interactive, through its own
widget? See [docs/FEASIBILITY.md](docs/FEASIBILITY.md) for the reasoning and
[docs/SPIKE.md](docs/SPIKE.md) for how to run the experiment and read its logs.
